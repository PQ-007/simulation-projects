# Conway's Game of Life

Тоглогчгүй "тоглоом". Та зөвхөн эхний зургаа зурна — үлдсэнийг 3 энгийн дүрэм өөрөө шийднэ. Гэтэл тэр дүрмүүдээс хөдөлдөг, буудаг, бүр тооцоолдог "амьтад" гарч ирдэг.

## Энгийнээр хэлбэл

Шатрын хөлөг шиг нүднүүд төсөөл. Нүд бүр **амьд** (өнгөтэй) эсвэл **үхсэн** (хоосон). Нүд бүр зөвхөн эргэн тойрныхоо **8 хөршийг** хардаг — хол юуг ч мэдэхгүй.

Алхам бүрт бүх нүд нэгэн зэрэг хөршүүдээ тоолоод шийднэ:

| Нөхцөл | Юу болох вэ | Яагаад |
| --- | --- | --- |
| Амьд нүд, 2 эсвэл 3 амьд хөрштэй | **Амьд үлдэнэ** | Тав тухтай |
| Амьд нүд, 0–1 хөрштэй | **Үхнэ** | Ганцаардал |
| Амьд нүд, 4+ хөрштэй | **Үхнэ** | Хэт бөөгнөрөл |
| Үхсэн нүд, яг 3 хөрштэй | **Амилна** | Шинэ төрөлт |

## Томьёо — алхам алхмаар

**1. Хөршөө тоолох.** $N$ = эргэн тойрны 8 нүдний хэд нь амьд вэ. Амьд нүд = 1, үхсэн = 0 гэж үзээд нэмнэ:

$$
N = \text{8 хөршийн нийлбэр}
$$

**2. Шийдвэр.** Дараагийн алхамд нүд амьд байх нөхцөл:

$$
\text{амьд} \iff N = 3 \;\;\text{эсвэл}\;\; (\text{одоо амьд ба } N = 2)
$$

Үгээр: *"яг 3 хөрштэй бол заавал амьд. 2 хөрштэй бол байсан хэвээрээ. Бусад бүх үед үхнэ."*

**Жишээ — "blinker".** Гурван амьд нүд хэвтээ эгнээнд (■ = амьд):

```text
. . . . .        . . . . .
. . . . .        . . ■ . .
. ■ ■ ■ .   →    . . ■ . .
. . . . .        . . ■ . .
. . . . .        . . . . .
```

- Голын нүдний **дээрх** хоосон нүд: доор нь 3 амьд хөрш → $N = 3$ → **амилна**.
- Зүүн захын амьд нүд: ганцхан хөрш (голынх) → $N = 1$ → **үхнэ**.
- Голын амьд нүд: 2 хөрш → $N = 2$ ба одоо амьд → **амьд үлдэнэ**.

Хэвтээ эгнээ босоо болно, дараагийн алхамд буцаад хэвтээ — мөнхөд анивчина!

## Хэрхэн ажилладаг вэ

1. Нүд бүрийн 8 хөршийн хэд нь амьд байгааг тоолно.
2. Дээрх дүрмээр нүд бүр амьдрах уу, үхэх үү гэдгийг шийднэ.
3. **Бүх** нүд шийдвэрээ гаргасны дараа л зэрэг шинэчлэгдэнэ.
4. Дахин давтана. Grid-ийн ирмэгүүд эсрэг талтайгаа холбоотой (Pac-Man шиг).

## Demo дээр туршаад үз

- **Glider** — 5 нүдтэй жижиг "амьтан" диагональ чиглэлд мөлхөнө. Хэн ч түүнд "яв" гэж хэлээгүй!
- **Gosper gun** — glider-уудыг тасралтгүй "буудаж" байгаа машин.
- **Pulsar** — зүрх шиг цохилдог хэлбэр. **R-pentomino** — ердөө 5 нүд, гэтэл 1000 гаруй алхам хөдөлнө.
- **Random** дараад хүлээ — эмх замбараагүй байдлаас тогтвортой хэлбэрүүд үүснэ.
- Нүд дээр дарж, чирж өөрөө зураад **▶ Эхлүүлэх**.

## Нэг санаа авч үлдэх

> **Энгийн дүрэм + олон давталт = нарийн төвөгтэй зан төлөв.** Үүнийг **emergence** гэдэг. Шоргоолжны үүр, шувууны сүрэг, замын түгжрэл ч ингэж үүсдэг — хэн ч удирдаагүй байхад.

## Код (C++)

Blinker-ийг 3 алхам ажиллуулж хэвлэдэг бүтэн программ:

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int W = 5, H = 5;
using Grid = vector<vector<int>>;            // 1 = амьд, 0 = үхсэн

int neighbours(const Grid& g, int x, int y) {
    int n = 0;
    for (int dy = -1; dy <= 1; dy++)
        for (int dx = -1; dx <= 1; dx++)
            if (dx || dy)                         // өөрийгөө тоолохгүй
                n += g[(y + dy + H) % H][(x + dx + W) % W];   // ирмэгээр тойрно
    return n;
}

Grid step(const Grid& g) {
    Grid next(H, vector<int>(W, 0));          // шинэ grid-ийг тусад нь бичнэ
    for (int y = 0; y < H; y++)
        for (int x = 0; x < W; x++) {
            int N = neighbours(g, x, y);
            next[y][x] = (N == 3 || (g[y][x] && N == 2)) ? 1 : 0;
        }
    return next;
}

void print(const Grid& g) {
    for (auto& row : g) { for (int c : row) cout << (c ? "# " : ". "); cout << "\n"; }
    cout << "\n";
}

int main() {
    Grid g(H, vector<int>(W, 0));
    g[2][1] = g[2][2] = g[2][3] = 1;          // хэвтээ blinker
    for (int i = 0; i < 3; i++) { print(g); g = step(g); }
}
```

Шинэ төлвийг **тусдаа** grid-д бичдэг нь чухал — эс тэгвээс аль хэдийн шинэчлэгдсэн хөршөө тоолох алдаа гарна. Demo-ийн бүтэн код: [demo.js](demo.js).
