# Finite State Machine

Тоглоомын дайсан яаж "бодож" байгаа юм шиг санагддаг вэ? Ихэнхдээ хариулт нь маш энгийн: тэр хэдхэн **төлөв**-ийн нэгд байдаг бөгөөд ямар нэг зүйл тохиолдоход дараагийн төлөв рүү шилждэг.

## Энгийнээр хэлбэл

Өөрийн өдрийг төсөөл: **Унтаж байна → Сэрэв → Хичээлд явж байна → Хичээл дээр байна → Гэртээ ирэв**. Нэг агшинд та яг **нэг** төлөвт байна. Төлөв солигдохын тулд ямар нэг **event** хэрэгтэй: сэрүүлэг дуугарах, хонх цохих...

State machine-д гурван л зүйл бий:

- **Төлөв** — одоо юу хийж байна (Patrol, Attack, Locked...).
- **Event** — юу тохиолдов (дайсан харагдлаа, зоос хийв...).
- **Шилжилт** — "энэ төлөвт энэ event ирвэл тийшээ шилж" гэсэн дүрэм.

## Томьёо — алхам алхмаар

Бүх state machine нэг л томьёо:

$$
\text{дараагийн төлөв} = \delta(\text{одоогийн төлөв},\ \text{event})
$$

$\delta$ ("дельта") нь зүгээр л **хүснэгт**. Мөр нь төлөв, багана нь event, нүд нь "хаашаа шилжих вэ":

| Төлөв \ Event | `s` дайсан харагдав | `r` буудах зайд | `h` health бага |
| --- | --- | --- | --- |
| **Patrol** | Chase | — | — |
| **Chase** | — | Attack | Flee |
| **Attack** | — | — | Flee |

"—" = шилжилт байхгүй: тэр event-ийг үл тоомсорлож, хэвээр үлдэнэ.

**Жишээ.** Bot **Patrol**-оос эхлээд `s`, `h`, `r`, `h` event-үүд ирэв:

| Алхам | Одоогийн төлөв | Event | Хүснэгтээс | Шинэ төлөв |
| --- | --- | --- | --- | --- |
| 1 | Patrol | `s` | $\delta$(Patrol, s) = Chase | **Chase** |
| 2 | Chase | `h` | $\delta$(Chase, h) = Flee | **Flee** |
| 3 | Flee | `r` | байхгүй | **Flee** (хэвээр) |
| 4 | Flee | `h` | байхгүй | **Flee** (хэвээр) |

Ердөө хүснэгтээс харах — тэгээд л болоо!

## Demo дээр туршаад үз

- **Game bot (AI)** — **Player**-ийг (хар ромбо) чирж bot руу ойртуул. Bot **Patrol → Chase → Attack** гэж шилжиж, graph дээр одоогийн төлөв тодорно. Health буурвал **Flee**, 0 болбол **Dead**.
- **Trace** мөр — ямар event-ээр ямар төлөв рүү шилжсэнийг дарааллаар нь харуулна (дээрх хүснэгт шиг).
- **Definition засах** — bot-ийн "тархийг" өөрчил! `Flee` гэсэн мөрүүдийг устгавал bot хэзээ ч зугтахгүй.
- **Turnstile** (`c` = зоос, `p` = түлхэх), **Traffic light** (`t` = timer) — **Step ▶**-ээр нэг нэгээр ажиллуул.

## Нэг санаа авч үлдэх

> **"Ухаалаг" зан төлөв = цөөн төлөв + тодорхой хүснэгт.** Pac-Man-ийн сүнс, лифт, гэрлэн дохио, утасны "loading / алдаа / амжилттай" дэлгэц — бүгд state machine.

## Код (C++)

Дээрх жишээг яг давтдаг бүтэн программ — $\delta$ хүснэгт нь `map`:

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    // δ(төлөв, event) = дараагийн төлөв
    map<pair<string, char>, string> delta = {
        {{"Patrol", 's'}, "Chase"},
        {{"Chase",  'r'}, "Attack"},
        {{"Chase",  'h'}, "Flee"},
        {{"Attack", 'h'}, "Flee"},
    };

    string state = "Patrol";
    for (char event : string("shrh")) {
        auto it = delta.find({state, event});
        if (it != delta.end()) state = it->second;   // байхгүй бол хэвээр
        cout << "event '" << event << "' -> " << state << "\n";
    }
}
```
