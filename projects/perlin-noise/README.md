# Perlin Noise

Minecraft-ийн уул, далай, агуйг хэн зурсан бэ? Хэн ч биш — **Perlin noise** гэдэг "гөлгөр санамсаргүй" тоонууд. Ken Perlin үүнийг 1983 онд зохиож, кино графикт оруулсан хувь нэмрээрээ Oscar шагнал авсан.

## Энгийнээр хэлбэл

Газрын зураг бүтээхдээ цэг бүрт санамсаргүй өндөр өгвөл яах вэ? **Зурагт шуугиан** шиг эмх замбараагүй — нэг цэг уулын орой, хажуугийн цэг нь далайн ёроол. Байгаль тийм биш: уул **аажмаар** өндөрсдөг.

Perlin noise-ийн нууц: санамсаргүй байдлыг зөвхөн **цөөн цэгт** (grid-ийн булан бүрт) тавиад, тэдгээрийн **хоорондох** бүх цэгийг гөлгөр холино.

## Томьёо — алхам алхмаар

### 1. Булан бүрт санамсаргүй сум

Grid-ийн булан бүрт санамсаргүй чиглэлтэй **сум** тавина. Demo дээр **Gradient сумнууд**-ыг асааж харна уу.

### 2. Dot product — "сум над руу заагаад байна уу?"

Булангийн сум $(a_x, a_y)$, булангаас манай цэг хүртэлх зай $(d_x, d_y)$ бол:

$$
\text{dot} = a_x \cdot d_x + a_y \cdot d_y
$$

- Сум бидэн рүү заагаад байвал → **эерэг** (өндөрлөг)
- Эсрэг тийш бол → **сөрөг** (хотгор)

**Жишээ:** сум баруун тийш $(1, 0)$, бид булангаас $(0.3, 0.2)$ зайд. $\text{dot} = 1 \cdot 0.3 + 0 \cdot 0.2 = 0.3$ → бага зэрэг өндөр.

### 3. Mix — хоёр тооны дунд

$$
\text{mix}(a, b, t) = a + (b - a) \cdot t
$$

$t = 0$ бол $a$, $t = 1$ бол $b$, хооронд нь аажмаар шилжинэ. **Жишээ:** $a = 2$, $b = 6$, $t = 0.25$ → $2 + 4 \cdot 0.25 = 3$ (2-оос 6 руу дөрөвний нэг явсан).

### 4. Fade — зөөлөн эхлэх, зөөлөн дуусах

Шулуун холивол нүдний хил дээр "хугарал" харагдана. Тиймээс $t$-г эхлээд ийм муруйгаар зөөлрүүлнэ:

$$
\text{fade}(t) = 6t^5 - 15t^4 + 10t^3
$$

| $t$ | 0 | 0.1 | 0.5 | 0.9 | 1 |
| --- | --- | --- | --- | --- | --- |
| fade | 0 | 0.009 | 0.5 | 0.991 | 1 |

Төгсгөл бүрт бараг хөдлөхгүй, дунд нь хурдан — машин зөөлөн хөдөлж, зөөлөн зогсдог шиг.

### 5. Octave — давхарлах

Нэг noise хэт гөлгөр (зөөлөн толгод). Бодит газар том уул + жижиг толгод + бүр жижиг чулуутай. Тиймээс хэд хэдэн noise-ийг **2 дахин нарийн, хагас хүчтэй** болгон нэмнэ:

$$
\text{өндөр} = 1 \cdot n(x) + \tfrac{1}{2} \cdot n(2x) + \tfrac{1}{4} \cdot n(4x) + \dots
$$

**Жишээ:** гурван octave $0.6,\ -0.2,\ 0.4$ гарсан бол $0.6 + 0.5 \cdot (-0.2) + 0.25 \cdot 0.4 = 0.6 - 0.1 + 0.1 = 0.6$.

## Demo дээр туршаад үз

- Газрын зургийг **чирж** яв, эсвэл **✈ Нисэх** — ертөнц хязгааргүй.
- **Octaves**-ийг 1 → 8 болго. Доорх **1D зүсэлт** дээр octave бүрийн долгион (өнгөт) нийлж нэг муруй (хар) болохыг хар.
- **🎲 Шинэ ертөнц** — ижил seed бол үргэлж ижил ертөнц (Minecraft-ийн seed шиг).
- **Усны түвшин**-ийг өсгөж арлууд, буулгаж тивүүд үүсгэ.

## Нэг санаа авч үлдэх

> **Санамсаргүй + гөлгөр = байгалийн мэт.** Уул, үүл, гал, модны хээ, камерын чичиргээ — тоглоом, кинонд "байгалийн" харагдах бараг бүх зүйл noise-оос гардаг.

## Код (C++)

2D Perlin noise-оор жижиг "газрын зураг" тэмдэгтээр зурдаг бүтэн программ (`~` ус, `.` элс, `"` өвс, `^` уул):

```cpp
#include <algorithm>
#include <cmath>
#include <iostream>
#include <random>
using namespace std;

double gradX[256], gradY[256];                // булан бүрийн санамсаргүй сум
int perm[512];

double fade(double t) { return t * t * t * (t * (t * 6 - 15) + 10); }
double mix(double a, double b, double t) { return a + (b - a) * t; }

// (ix, iy) булангийн сум ба цэг хүртэлх зайн dot product
double corner(int ix, int iy, double dx, double dy) {
    int h = perm[(ix & 255) + perm[iy & 255]];
    return gradX[h] * dx + gradY[h] * dy;
}

double noise(double x, double y) {
    int x0 = floor(x), y0 = floor(y);
    double fx = x - x0, fy = y - y0;          // нүдний дотор хаана байна
    double a = corner(x0, y0, fx, fy),     b = corner(x0 + 1, y0, fx - 1, fy);
    double c = corner(x0, y0 + 1, fx, fy - 1), d = corner(x0 + 1, y0 + 1, fx - 1, fy - 1);
    double u = fade(fx), v = fade(fy);
    return mix(mix(a, b, u), mix(c, d, u), v);
}

int main() {
    mt19937 rng(42);                          // ижил seed = ижил ертөнц
    for (int i = 0; i < 256; i++) {
        double angle = uniform_real_distribution<double>(0, 2 * M_PI)(rng);
        gradX[i] = cos(angle); gradY[i] = sin(angle); perm[i] = i;
    }
    shuffle(perm, perm + 256, rng);
    for (int i = 0; i < 256; i++) perm[256 + i] = perm[i];

    for (int y = 0; y < 20; y++) {
        for (int x = 0; x < 60; x++) {
            double h = 0, amp = 1, freq = 1;
            for (int o = 0; o < 4; o++) {     // 4 octave
                h += amp * noise(x * 0.08 * freq, y * 0.16 * freq);
                amp /= 2; freq *= 2;
            }
            cout << (h < -0.1 ? '~' : h < 0 ? '.' : h < 0.35 ? '"' : '^');
        }
        cout << "\n";
    }
}
```
