# Trie

Утсан дээр "сай" гэж бичихэд "сайн", "сайхан" гэж санал болгодог. Google-д "how to" гэж бичихэд доор нь олон асуулт гарч ирдэг. Тэр бүгдийн ард **Trie** (трай, "prefix tree") гэдэг энгийн мод байдаг.

## Энгийнээр хэлбэл

Толь бичиг төсөөл. "сайхан" гэдэг үгийг хайхдаа та бүх хуудсыг нэг бүрчлэн уншдаггүй: эхлээд **С** хэсэг рүү, дотроос нь **СА**, дараа нь **САЙ**... Үсэг бүр таныг илүү жижиг хэсэг рүү чиглүүлнэ.

Trie яг ингэж хадгалдаг:

- **Мод** бол үсгүүдийн зам. Root-оос эхэлж, үсэг бүр нэг алхам.
- Ижил **эхлэлтэй** үгс замаа **хуваалцана**: "car", "cat", "cart" бүгд `c → a` замаар явна.
- Үгийн төгсгөлийн нүдийг **тэмдэглэнэ** (demo дээр цэнхэр) — "car" нь "cart"-ын замын дунд байгаа ч бүтэн үг гэдгийг мэдэхийн тулд.

```text
root
 └ c
   └ a
     ├ r ●          ← "car" (● = үгийн төгсгөл)
     │ ├ t ●        ← "cart"
     │ └ e ●        ← "care"
     └ t ●          ← "cat"
```

## Томьёо — алхам алхмаар

### 1. Хайлтын хурд — үгийн уртаас л хамаарна

$$
\text{хайх алхам} = L \quad (\text{үгийн урт})
$$

Толь бичигт хичнээн үг байх нь **хамаагүй**!

**Жишээ:** толь бичигт **1 000 000** үг байна, "cat" гэж хайна.

| Арга | Алхам |
| --- | --- |
| Жагсаалтыг нэг бүрчлэн шалгах | 1 000 000 хүртэл |
| Trie | **3** (`c`, `a`, `t`) |

### 2. Хэмнэлт — хуваалцсан эхлэл

$$
\text{нүдний тоо} \le \text{бүх үгийн үсгийн нийлбэр}
$$

**Жишээ:** "car" (3) + "cat" (3) + "cart" (4) = **10 үсэг**. Гэтэл trie-д ердөө **5 нүд**: `c`, `a`, `r`, `t` (car-ын), `t` (cat-ын). `c → a` хоёр нүдийг гурван үг хуваалцсан, `c → a → r` гурвыг "car", "cart" хуваалцсан.

### 3. Autocomplete — эхлэлийн доорх бүх үг

"ca" гэж бичихэд:

1. `c → a` гэж **2 алхам** явж тэр нүдэнд хүрнэ.
2. Тэр нүднээс доошх **бүх** тэмдэглэсэн нүдийг цуглуулна: **car, care, cart, cat**.

Бүтэн толь бичгийг биш, зөвхөн тэр жижиг "мөчир"-ийг шалгана.

### 4. Байхгүй үг — эрт мэдэх

"cow" гэж хайхад `c` бий, гэхдээ түүний доор `o` салаа **алга** → 2-р алхамд л "ийм эхлэлтэй үг огт байхгүй" гэж мэднэ. Үлдсэнийг шалгах шаардлагагүй.

## Demo дээр туршаад үз

- **Жишээ** толь бичигт `ca` гэж бич — зам **шараар** тодорч, доор нь **car, card, care, cart, cat** санал гарна.
- `cow` гэж бич — `c`-ийн дараа **улаан тасархай** салаа: "o" байхгүй!
- `cab` гэж бичээд **+ Нэмэх** — зөвхөн `b` гэсэн **1 шинэ нүд** (ногоон) нэмэгдэнэ, бусдыг хуваалцсан.
- **English** (≈200 үг) сонгоод `b`, `br`, `bri` гэж бич — том модноос зөвхөн хэрэгтэй мөчир харагдана. Доор "жагсаалтаар хайвал 200 үгийг шалгах байсан" гэж харьцуулна.
- **Монгол**, **Код** толь бичгүүдийг ч туршаад үз (кодын editor-ийн autocomplete шиг).

## Нэг санаа авч үлдэх

> **Эхлэлийг хуваалцаж хадгалбал хайлт үгийн тооноос биш, үгийн уртаас хамаарна.** Утасны keyboard, Google-ийн санал, spell checker, кодын autocomplete, router — бүгд энэ санаа.

## Код (C++)

Trie үүсгэж, үг нэмж, "ca" эхлэлтэй үгсийг хэвлэдэг бүтэн программ:

```cpp
#include <iostream>
#include <map>
#include <memory>
#include <string>
#include <vector>
using namespace std;

struct Node {
    map<char, unique_ptr<Node>> kids;    // үсэг → дараагийн нүд (цагаан толгойн дарааллаар)
    bool isWord = false;                 // энд үг дуусах уу
};

struct Trie {
    Node root;
    int nodes = 0;

    void insert(const string& word) {
        Node* n = &root;
        for (char c : word) {
            if (!n->kids.count(c)) { n->kids[c] = make_unique<Node>(); nodes++; }   // байхгүй бол шинэ нүд
            n = n->kids[c].get();
        }
        n->isWord = true;
    }

    Node* find(const string& prefix) {   // L алхам
        Node* n = &root;
        for (char c : prefix) {
            auto it = n->kids.find(c);
            if (it == n->kids.end()) return nullptr;   // салаа алга: ийм эхлэл байхгүй
            n = it->second.get();
        }
        return n;
    }

    void collect(Node* n, string word, vector<string>& out) {   // мөчрийн бүх үг
        if (n->isWord) out.push_back(word);
        for (auto& [c, kid] : n->kids) collect(kid.get(), word + c, out);
    }
};

int main() {
    Trie t;
    for (string w : {"car", "cat", "cart", "care", "card", "dog", "do"}) t.insert(w);

    vector<string> out;
    if (Node* n = t.find("ca")) t.collect(n, "ca", out);
    cout << "\"ca\" -> ";
    for (auto& w : out) cout << w << " ";
    cout << "\n";

    cout << "\"cow\" байна уу? " << (t.find("cow") ? "тийм" : "үгүй") << "\n";
    cout << "Нүдний тоо: " << t.nodes << "\n";
}
```

Гаралт: `"ca" -> car card care cart cat`, `"cow" байна уу? үгүй`, `Нүдний тоо: 10` (7 үгийн 23 үсгийг 10 нүдэнд багтаасан). Demo-ийн бүтэн код: [demo.js](demo.js).
