# Compression Algorithms

ZIP файл яаж жижгэрдэг вэ? Вэб хуудас яаж хурдан ачаалагддаг вэ? Нууц нь: өгөгдөлд **давтагддаг зүйл** их байдаг бөгөөд тэдгээрийг ухаалгаар "товчилж" бичиж болно. Эцэст нь bit бүрийг яг буцааж сэргээнэ — нэг ч үсэг алдахгүй (**lossless**).

## Энгийнээр хэлбэл

Найздаа утсаар зааварчилгаа уншиж өгч байна гэж төсөөл. Ухаалаг хүн гурван арга хэрэглэдэг:

| Арга | Хүний жишээ | Algorithm |
| --- | --- | --- |
| **"N удаа"** | "АААААААААА" гэхийн оронд "10 ширхэг А" | **RLE** |
| **Түгээмэлд богино нэр** | Байнга хэлдэг үгэндээ товчлол хэрэглэх | **Huffman** |
| **"Дээр хэлсэн шиг"** | Давтагдсан өгүүлбэрийг "өмнөхийг дахиад" гэх | **LZ77** |

## Томьёо — алхам алхмаар

### 1. Bit — компьютерийн үсэг

Компьютер бүх зүйлийг 0, 1-ээр (**bit**) хадгална. Энгийн үсэг бүр **8 bit**. "banana" = 6 үсэг × 8 = **48 bit**.

### 2. RLE — "хэдэн удаа"

`AAAABBB` → `4A 3B`. Үсэг давтагдах тусам хэмнэнэ. Харин `ABCD` → `1A 1B 1C 1D` — **томорно**!

### 3. Huffman — олон гардагт богино code

**Жишээ: "banana"**. Үсэг бүр хэдэн удаа гарав: `a` 3, `n` 2, `b` 1.

Мод барих: **хамгийн цөөн хоёрыг** нэгтгэнэ, дахин давтана:

1. Хамгийн цөөн нь `b`(1), `n`(2) → нэгтгэж **3** болгоно.
2. Үлдсэн `a`(3), `bn`(3) → нэгтгэж **6** болгоно. Мод бэлэн.

Зүүн салаа = `0`, баруун = `1`:

```text
        (6)
       0/  \1
      a    (3)
          0/  \1
          b    n
```

| Үсэг | Code | Хэдэн удаа | Bit |
| --- | --- | --- | --- |
| a | `0` | 3 | 3 × 1 = 3 |
| b | `10` | 1 | 1 × 2 = 2 |
| n | `11` | 2 | 2 × 2 = 4 |
| **Нийт** | | | **9 bit** |

$$
\text{нийт bit} = \sum (\text{хэдэн удаа} \times \text{code-ийн урт})
$$

48 bit → **9 bit**! Ямар ч code өөр code-ийн эхлэл биш тул `0101110` гэх мэт урсгалыг тусгаарлагчгүйгээр уншиж болно.

### 4. Entropy — шахалтын хязгаар

$$
H = -\sum p \cdot \log_2 p
$$

Айх хэрэггүй. $\log_2 \frac{1}{p}$ гэдэг нь *"тэр үсгийг таахын тулд хэдэн **тийм/үгүй** асуулт хэрэгтэй вэ"*:

- Хагас нь `a` ($p = \frac{1}{2}$) → 1 асуулт ("a мөн үү?")
- Дөрөвний нэг ($p = \frac{1}{4}$) → 2 асуулт
- Наймны нэг ($p = \frac{1}{8}$) → 3 асуулт

**"banana"-д:** $p(a) = \frac{3}{6},\ p(n) = \frac{2}{6},\ p(b) = \frac{1}{6}$. $H \approx 0.5 \cdot 1 + 0.33 \cdot 1.58 + 0.17 \cdot 2.58 \approx 1.46$ bit/үсэг. 6 үсэг → **≈ 8.75 bit** — үсэг бүрийг тусад нь кодлоход үүнээс бага болох **боломжгүй**. Huffman 9 bit — маш ойрхон!

Бүрэн **санамсаргүй** өгөгдлийн entropy хамгийн их тул шахагдахгүй — ZIP-ийг дахин ZIP хийхэд жижгэрдэггүй нь үүнээс.

### 5. LZ77 — "өмнөхөөс хуул"

`abcabcabc` → `a b c ⟲(3, 6)` = *"3 тэмдэгтийн өмнөхөөс эхлээд 6-г хуул"*. Хуулж байхдаа шинээр бичсэнээ ч хуулж болно — тиймээс 3 үсгээс 6-г гаргаж чадна.

## Demo дээр туршаад үз

- **banana** → **Huffman** таб → **⏮**, дараа нь **Нэгтгэх ▶** — дээрх модыг өөрөө барь.
- **AAAA…**, **Fax мөр** дээр **RLE** — их хэмнэнэ. **English** дээр RLE — томорно!
- **Дуу** → **LZ77** — давтагдсан мөр нэг "⟲" хуулбар болно. Chip дээр хулганаа аваач.
- **Харьцуулах** — бүх аргыг browser-ийн жинхэнэ **gzip**, entropy-ийн хязгаартай (улаан шугам) тулга. **Random** дээр юу болох вэ?

## Нэг санаа авч үлдэх

> **Шахалт = давталтыг олох.** Давталт их байх тусам жижиг; санамсаргүй зүйлийг шахах боломжгүй. ZIP, PNG, вэб хуудас, Netflix video, Game Boy-ийн Pokémon — бүгд энэ санаа.

## Код (C++)

"banana"-гийн Huffman мод барьж code-уудыг хэвлэдэг бүтэн программ:

```cpp
#include <iostream>
#include <map>
#include <queue>
#include <string>
#include <vector>
using namespace std;

struct Node {
    int count; char ch; Node* left = nullptr; Node* right = nullptr;
};
struct Fewer {   // priority_queue хамгийн цөөнийг түрүүлж гаргана
    bool operator()(Node* a, Node* b) const { return a->count > b->count; }
};

void collect(Node* n, const string& code, map<char, string>& codes) {
    if (!n->left) { codes[n->ch] = code.empty() ? "0" : code; return; }
    collect(n->left, code + "0", codes);       // зүүн = 0
    collect(n->right, code + "1", codes);      // баруун = 1
}

int main() {
    string text = "banana";
    map<char, int> freq;
    for (char c : text) freq[c]++;

    priority_queue<Node*, vector<Node*>, Fewer> trees;
    for (auto [c, f] : freq) trees.push(new Node{f, c});
    while (trees.size() > 1) {                 // хамгийн цөөн хоёрыг нэгтгэх
        Node* a = trees.top(); trees.pop();
        Node* b = trees.top(); trees.pop();
        trees.push(new Node{a->count + b->count, 0, a, b});
    }

    map<char, string> codes;
    collect(trees.top(), "", codes);
    int bits = 0;
    for (auto [c, code] : codes) {
        cout << c << " = " << code << "\n";
        bits += freq[c] * code.size();
    }
    cout << "Нийт: " << bits << " bit (эх нь " << text.size() * 8 << " bit)\n";
}
```

Тэнцүү давтамжтай үед аль нь зүүн, аль нь баруун орох нь өөр байж болох тул code-ууд арай өөр гарч болно — гэхдээ **нийт 9 bit** үргэлж ижил. Demo-ийн бүтэн код: [demo.js](demo.js).
