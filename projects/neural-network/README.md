# Neural Network Playground

ChatGPT, царайгаар утас нээх, өөрөө жолооддог машин, зураг таних — бүгд **neural network**. Нууц биш: энэ бол олон жижиг "нэмэх, үржих"-ийг давхарласан функц, мөн түүний тоонуудыг **алдаанаасаа суралцан** тохируулдаг арга. Энэ project-д жижиг сүлжээ цэгүүдийг ялгаж сурахыг, ялгах хил нь хэрхэн муруйж байгааг шууд харна.

## Энгийнээр хэлбэл — хүүхдийн таавар

Нэг хүүхэд "энэ жимс алим уу, жүрж үү?" гэдгийг сурч байна гэж төсөөл. Өнгө, хэлбэр, жин гэсэн **зүйлсийг** (оролт) харна. Эхэндээ санамсаргүй таана. Буруу таавал та "үгүй" гэнэ — хүүхэд **аль зүйл дээр илүү анхаарах вэ** гэдгээ жаахан өөрчилнө. Мянга удаа давтвал зөв таадаг болно.

Neural network яг ингэж суралцдаг:

| Хүүхэд | Neural network |
| --- | --- |
| Харсан зүйлс (өнгө, жин…) | **Оролт** (demo-д x, y координат) |
| "Энэ зүйл хэр чухал" гэсэн бодол | **Жин** (weight) — тоо |
| Таамаг | **Гаралт** (0–1 хоорондох магадлал) |
| "Үгүй, буруу!" | **Loss** (алдаа) |
| Бодлоо жаахан өөрчлөх | **Gradient descent** (жинг тохируулах) |

## 1. Neuron — жижиг тооцоолуур

Нэг neuron: оролт бүрийг **жингээр үржүүлээд нэмж**, жаахан **bias** (хазайлт) нэмээд, "асаах функц"-ээр дамжуулна.

$$
z = w_1 x_1 + w_2 x_2 + b \qquad \text{гаралт} = f(z)
$$

**Жишээ:** $x_1 = 1,\ x_2 = 0.5$, жин $w_1 = 0.8,\ w_2 = -0.4$, $b = 0.1$:

$$
z = 0.8 \cdot 1 + (-0.4) \cdot 0.5 + 0.1 = 0.8 - 0.2 + 0.1 = 0.7
$$

**Асаах функц** $f$ нь $z$-ийг "дарж" нэг хэмжээнд оруулна:

| $z$ | −3 | −1 | 0 | 0.7 | 3 |
| --- | --- | --- | --- | --- | --- |
| $\tanh(z)$ | −0.995 | −0.76 | 0 | **0.604** | 0.995 |
| $\sigma(z)$ (sigmoid) | 0.047 | 0.27 | 0.5 | **0.668** | 0.953 |

Хэтэрхий том, хэтэрхий жижиг $z$ ихэнхдээ −1/+1 (tanh) эсвэл 0/1 (sigmoid) болно — "асалттай / унтраалттай" шиг. Яагаад асаах функц хэрэгтэй вэ? Түүнгүйгээр олон давхарга нэг шулуун томьёо болж хураагддаг — муруй хил гаргаж чадахгүй.

## 2. Давхарга — neuron-уудыг давхарлах

Neuron-уудыг мөр болгон (давхарга) байрлуулж, нэг давхаргын гаралтыг дараагийн давхаргын оролт болгоно. Demo-ийн дүрслэл дээр **цэнхэр шугам = эерэг жин**, **улаан = сөрөг жин**, зузаан нь том жин.

$$
\text{параметрийн тоо} = \sum (\text{оролт} \times \text{neuron} + \text{neuron})
$$

**Жишээ:** `2 → 4 → 3 → 1` сүлжээ: $(2 \cdot 4 + 4) + (4 \cdot 3 + 3) + (3 \cdot 1 + 1) = 12 + 15 + 4 = $ **31 параметр**. Demo-д 4 оролт, 2 hidden давхарга (4, 3) → 51.

ChatGPT-д мөн адил, зөвхөн параметр нь **хэдэн зуун тэрбум**.

## 3. Loss — "хэр буруу байна?"

Зөв хариу $y = 1$ үед сүлжээ магадлал $p$ гэж таавал алдаа:

$$
\text{loss} = -\ln(p) \quad (y = 1 \text{ үед})
$$

| Таамаг $p$ | 0.99 | 0.9 | 0.5 | 0.1 | 0.01 |
| --- | --- | --- | --- | --- | --- |
| Loss | 0.01 | 0.105 | **0.693** | 2.30 | 4.6 |

Зөв гэж итгэлтэй байх (0.99) нь бараг алдаагүй; **итгэлтэй буруу** байх (0.01) нь маш их шийтгэнэ. 0.5 (таамаг хийж чадахгүй) нь 0.693 — demo-ийн loss график дээрх тасархай шугам. Сургалт эхлэхэд loss 0.69 орчим, дараа нь буурах ёстой.

## 4. Gradient descent — налуугаар уруудах

Loss-ийг хамгийн багаар хийх жинг яаж олох вэ? **Уулын энгэр дээр сохроор зогсож байгаа** хүн шиг: хөл доорх налууг мэдэрч, налуугийн **эсрэг** (доошоо) жаахан алхана.

$$
w \leftarrow w - \text{learning rate} \times \text{налуу}
$$

**Жишээ.** Loss $= (w - 3)^2$ (хамгийн бага нь $w = 3$), $w = 0$-оос эхэлж, learning rate = 0.1. Налуу $= 2(w - 3)$:

| Алхам | $w$ | Налуу | Loss |
| --- | --- | --- | --- |
| 0 | 0 | −6 | 9 |
| 1 | 0.6 | −4.8 | 5.76 |
| 2 | 1.08 | −3.84 | 3.69 |
| 3 | 1.464 | −3.07 | 2.36 |
| 4 | 1.771 | … | 1.51 |

$w$ 3 рүү ойртож, налуу багасаж, алхам жижгэрч байна. **Learning rate** хэт жижиг бол удаан, хэт том бол хэт алхаж хаяа давна. Demo-ийн гулсуураар туршиж үз!

## 5. Backpropagation — алдааг буцааж түгээх

Сүлжээнд олон мянган жин байна. Жин бүрийн налууг яаж олох вэ? **Алдааг гаралтаас эхлэн буцаан** түгээнэ: сүүлийн давхарга "би энэ хэмжээгээр буруу байсан" гэж өмнөх давхаргад хэлнэ, тэр нь өөрийн өмнөх рүү... Ингэх нь **chain rule** (гинжин дүрэм) — өөрчлөлтийн нөлөө давхаргаар дамжих.

Гаралтад sigmoid + cross-entropy хослуулбал алдааны томьёо маш энгийн болно:

$$
\text{гаралтын алдаа} = p - y
$$

Зөв хариу 1, таамаг 0.9 бол алдаа $0.9 - 1 = -0.1$ (жаахан доогуур); таамаг 0.1 бол $-0.9$ (маш доогуур). Түүнийг жин бүрийн оролтоор үржүүлж налууг гаргана.

## 6. Яагаад hidden давхарга хэрэгтэй вэ?

**XOR** тохиолдол: цэг $x \cdot y > 0$ үед (эхний, гурав дахь квадрант) нэг анги, бусад нь нөгөө анги. **Нэг шулуунаар хоёр ангийг салгах боломжгүй.** Hidden давхаргагүй сүлжээ ердөө шулуун хил гаргана — XOR дээр ~50–65% л зөв. Hidden давхарга нэмэхэд сүлжээ шулууныг **нийлүүлж** муруй хил гаргана. Demo-д **XOR** сонгоод **− layer**-аар hidden-г хасаж үз — хэзээ ч суралцахгүй!

Мөн **оролтыг сайжруулж** болно: $x \cdot y$ гэсэн нэмэлт оролт өгөхөд hidden давхаргагүй ч XOR шийдэгдэнэ — яагаад гэвэл шинэ оролт өөрөө хэрэгтэй "муруйлт"-ыг өгч байна. Үүнийг **feature engineering** гэдэг.

## Demo дээр туршаад үз

- **Дугуй** өгөгдөл сонгоод **▶ Сургах**. Эхэндээ бүх зүйл бүдэг (таамаг 0.5); аажмаар дугуй хэлбэртэй цэнхэр бүс үүснэ. Loss графикийн 0.69-ээс буурахыг хар. **Буруу таасан цэг шар хүрээтэй** — тэдгээр аажмаар алга болно.
- **Спираль** — хамгийн хэцүү. Эхлээд `sin x`, `sin y` оролт нэмж, hidden давхарга (8, 6) болго. Хил спираль хэлбэрээр ороосон болно.
- **x², y²** оролтоор **Дугуй**-г 2 neuron-той л шийд. Сүлжээ жижиг үед ч зөв оролт тусална!
- **Learning rate**-ийг маш бага (0.01) болго — удаан. Маш том (5) болго — loss савлана, суралцахгүй.
- Хулганаар **өөрийн цэг нэм** (🔵/🔴 сонгоод), хил өөрчлөгдөхийг хар. Shift дараад нөгөө анги.

## Нэг санаа авч үлдэх

> **Neural network = олон энгийн тооцоолуурын давхарга + алдаанаасаа суралцдаг арга.** Ид шид биш: цэг бүрт "зөв үү, буруу юу?" гэж шалгаад, жинг нь жаахан жаахнаар зөв тийш нь түлхэнэ. Мянга, сая, тэрбум дахин.

## Код (C++)

**1. Нэг neuron ба gradient descent** — дээрх гар тооцоололтой яг ижил:

```cpp
#include <cmath>
#include <iostream>
using namespace std;

int main() {
    // Нэг neuron: оролтуудыг жингээр үржүүлж нэмээд, bias нэмээд, "асаах функц"-ээр дамжуулна
    double x1 = 1.0, x2 = 0.5;          // оролт
    double w1 = 0.8, w2 = -0.4;         // жин (weights)
    double bias = 0.1;
    double z = w1 * x1 + w2 * x2 + bias;                // 0.8 - 0.2 + 0.1
    cout << "z       = " << z << "\n";
    cout << "tanh(z) = " << tanh(z) << "\n";            // -1…1 хооронд
    cout << "sigmoid = " << 1 / (1 + exp(-z)) << "\n";  // 0…1 хооронд (магадлал)

    // Gradient descent: loss = (w - 3)^2, хамгийн бага нь w = 3
    double w = 0, lr = 0.1;
    for (int step = 0; step <= 4; step++) {
        cout << "алхам " << step << ": w = " << w << ", loss = " << (w - 3) * (w - 3) << "\n";
        double slope = 2 * (w - 3);                     // налуу (gradient)
        w -= lr * slope;                                // налууны эсрэг тийш жаахан алхана
    }
}
```

Гаралт: `z = 0.7`, `tanh(z) = 0.604368`, `sigmoid = 0.668188`, дараа нь `w`: 0 → 0.6 → 1.08 → 1.464 → 1.7712.

**2. XOR сурдаг бүтэн сүлжээ** — 2 оролт, 3 hidden neuron, 1 гаралт. Урагш тооцоолол, loss, backpropagation, gradient descent бүгд энд:

```cpp
#include <cmath>
#include <iostream>
#include <random>
using namespace std;

const int H = 3;                                   // hidden neuron-ы тоо
double W1[H][2], B1[H], W2[H], B2;                 // сүлжээний бүх параметр

double sigmoid(double z) { return 1 / (1 + exp(-z)); }

// Урагш тооцоолох: оролт -> hidden (tanh) -> гаралт (sigmoid)
double forward(const double x[2], double hidden[H]) {
    double z = B2;
    for (int j = 0; j < H; j++) {
        hidden[j] = tanh(W1[j][0] * x[0] + W1[j][1] * x[1] + B1[j]);
        z += W2[j] * hidden[j];
    }
    return sigmoid(z);
}

int main() {
    mt19937 rng(7);
    uniform_real_distribution<double> r(-1, 1);
    for (int j = 0; j < H; j++) { W1[j][0] = r(rng); W1[j][1] = r(rng); B1[j] = 0; W2[j] = r(rng); }
    B2 = 0;

    // XOR: хоёр оролт ялгаатай үед 1
    double X[4][2] = {{0, 0}, {0, 1}, {1, 0}, {1, 1}};
    double Y[4] = {0, 1, 1, 0};
    double lr = 0.5;

    for (int epoch = 0; epoch <= 5000; epoch++) {
        double gW1[H][2] = {}, gB1[H] = {}, gW2[H] = {}, gB2 = 0, loss = 0;
        for (int n = 0; n < 4; n++) {
            double h[H], p = forward(X[n], h);
            loss -= Y[n] * log(p) + (1 - Y[n]) * log(1 - p);
            double dz = p - Y[n];                           // гаралтын алдаа (sigmoid + cross-entropy)
            gB2 += dz;
            for (int j = 0; j < H; j++) {
                gW2[j] += dz * h[j];
                double dh = dz * W2[j] * (1 - h[j] * h[j]); // алдааг hidden рүү буцаана (tanh-ийн налуу)
                gB1[j] += dh;
                gW1[j][0] += dh * X[n][0];
                gW1[j][1] += dh * X[n][1];
            }
        }
        // gradient descent: параметр бүрийг налууныхаа эсрэг жаахан хөдөлгөнө
        B2 -= lr * gB2 / 4;
        for (int j = 0; j < H; j++) {
            W2[j] -= lr * gW2[j] / 4; B1[j] -= lr * gB1[j] / 4;
            W1[j][0] -= lr * gW1[j][0] / 4; W1[j][1] -= lr * gW1[j][1] / 4;
        }
        if (epoch % 1000 == 0) cout << "epoch " << epoch << "  loss = " << loss / 4 << "\n";
    }
    for (int n = 0; n < 4; n++) {
        double h[H];
        cout << X[n][0] << " XOR " << X[n][1] << " -> " << forward(X[n], h) << "\n";
    }
}
```

Гаралт: loss `0.70` → `0.006` → … → `0.001`, мөн `0 XOR 0 -> 0.001`, `0 XOR 1 -> 0.999`, `1 XOR 0 -> 0.999`, `1 XOR 1 -> 0.001`. Сүлжээ XOR-ыг хэнээс ч заалгүй, **өөрөө сурсан**! Demo-ийн бүтэн код (олон давхарга): [demo.js](demo.js).
