# Boids

1986 онд Craig Reynolds шувуу, загасны сүргийг загварчилсан. Удирдагч ч, төв төлөвлөгөө ч байхгүй — boid бүр зөвхөн **ойролцоох хөршүүдээ** хараад гурван энгийн дүрмээр хөдөлнө. Гэтэл бүхэлдээ жинхэнэ сүрэг шиг нисдэг. Энэ бол **emergence**: энгийн local дүрмээс нарийн global зан төлөв үүсэх.

## Гурван дүрэм

Boid $i$-ийн байрлал $\mathbf{p}_i$, хурд $\mathbf{v}_i$. Харах радиус $r$ дотор байгаа хөршүүд нь $N_i$:

$$
N_i = \{\, j \neq i : |\mathbf{p}_j - \mathbf{p}_i| < r \,\}
$$

1. **Separation** 🔴 — хэт ойрхон хөршөөс холдох. Ойр байх тусам хүчтэй түлхэнэ:
$$
\mathbf{s}_i = -\sum_{j \in N_i} \frac{\mathbf{p}_j - \mathbf{p}_i}{|\mathbf{p}_j - \mathbf{p}_i|^2}
$$

2. **Alignment** 🟢 — хөршүүдийн дундаж чиглэлээр нисэх:
$$
\mathbf{a}_i = \frac{1}{|N_i|} \sum_{j \in N_i} \mathbf{v}_j
$$

3. **Cohesion** 🔵 — хөршүүдийн төв рүү ойртох:
$$
\mathbf{c}_i = \frac{1}{|N_i|} \sum_{j \in N_i} \mathbf{p}_j \;-\; \mathbf{p}_i
$$

## Steering

Дүрэм бүр "хаашаа явмаар байна" гэсэн **хүссэн чиглэл** өгнө. Түүнийг хүч болгохдоо хүссэн хурдаас одоогийн хурдыг хасаад, дээд хэмжээгээр хязгаарлана (Reynolds-ийн steering):

$$
\text{steer}(\mathbf{d}) = \text{limit}\Big(\hat{\mathbf{d}} \cdot v_{\max} - \mathbf{v}_i,\ F_{\max}\Big)
$$

Гурвыг жингээр нь нэмж, хурдыг шинэчилнэ:

$$
\mathbf{v}_i \leftarrow \mathbf{v}_i + \big(w_s\,\text{steer}(\mathbf{s}_i) + w_a\,\text{steer}(\mathbf{a}_i) + w_c\,\text{steer}(\mathbf{c}_i)\big)\,\Delta t
$$

## Хэрхэн ашиглах

- **Separation / Alignment / Cohesion** гулсуураар жинг өөрчил:
  - Alignment = 0 → сүрэг үүсэхгүй, boid-ууд санамсаргүй нисдэг.
  - Cohesion их → нягт бөөгнөрөл; Separation их → тархсан, жигд зайтай.
  - Радиус бага → олон жижиг сүрэг; их → нэг том сүрэг.
- **Хулгана**: **Махчин 🦅** горимд boid-ууд хулганаас зугтаж, сүрэг хуваагдана. **Хоол 🍞** горимд хулгана руу татагдана.
- **Нэг boid-ийг задлан харах** — хар boid-ийн харах радиус, хөршүүд, гурван хүчийг (🔴 separation, 🟢 alignment, 🔵 cohesion) сумаар харуулна.
- Өнгө нь нисэх чиглэлийг заана — нэг чиглэлд нисэж буй сүрэг нэг өнгөтэй.
- **Skin**: **Шувуу 🐦** (далавчаа дэвэнэ), **Загас 🐟** (сүүлээ шарвана, усан дэвсгэртэй) эсвэл энгийн **Сум ➤**. Дүрс өөр ч дүрэм нь яг ижил — шувууны сүрэг, загасны сүрэг хоёулаа boids.

## Код

Гурван дүрэм нэг давталтад:

```js
for (const o of neighbours(b)) {
  const dx = o.x - b.x, dy = o.y - b.y, d2 = dx * dx + dy * dy;
  ax += o.vx; ay += o.vy;              // alignment: хурдуудын нийлбэр
  cx += dx;   cy += dy;                // cohesion: төв рүү чиглэсэн
  if (d2 < (r * 0.45) ** 2) {          // separation: зөвхөн хэт ойрхон хөрш
    sx -= dx / d2; sy -= dy / d2;
  }
  n++;
}
const sep = steer(b, sx, sy), ali = steer(b, ax / n, ay / n), coh = steer(b, cx / n, cy / n);
b.ax = wSep * sep[0] + wAli * ali[0] + wCoh * coh[0];
b.ay = wSep * sep[1] + wAli * ali[1] + wCoh * coh[1];
```

Бүх boid-ийг хоорондоо харьцуулбал $O(n^2)$. Үүний оронд дэлгэцийг радиустай тэнцүү **spatial hash** нүднүүдэд хувааж, boid бүр зөвхөн эргэн тойрны 3 × 3 нүдийг шалгадаг тул бараг $O(n)$ болно.
