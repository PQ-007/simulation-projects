# Boids

Мянга мянган шувуу тэнгэрт нэг бие мэт урсаж нисдэг. Тэдэнд удирдагч бий юу? Үгүй. Шувуу бүр зөвхөн **хажуудах хэдэн хөршөө** хараад 3 энгийн дүрэм дагадаг. 1986 онд Craig Reynolds үүнийг компьютер дээр анх загварчилж "boids" гэж нэрлэсэн.

## Энгийнээр хэлбэл

Олон хүнтэй гудамжаар алхаж байна гэж төсөөл. Та өөрийн мэдэлгүй гурван зүйл хийдэг:

| Дүрэм | Хүний жишээ | Шувуу |
| --- | --- | --- |
| 🔴 **Separation** | Хүмүүст мөргөлдөхгүй зай барина | Хөршөөсөө холдоно |
| 🟢 **Alignment** | Урсгалын чиглэлээр алхана | Хөршүүдийн дундаж чиглэлээр нисэнэ |
| 🔵 **Cohesion** | Найзуудаасаа хол хоцрохгүй | Хөршүүдийн төв рүү ойртоно |

## Томьёо — алхам алхмаар

Гурван дүрэм бүгд **дундаж** (average) — "хэд хэдэн тоог нэмээд, тоонд нь хуваах".

**Жишээ нөхцөл:** би $(0, 0)$-д байна. Хоёр хөрш:

- Хөрш A: байрлал $(2, 0)$, нисэх чиглэл $(1, 0)$ — баруун тийш
- Хөрш B: байрлал $(0, 2)$, нисэх чиглэл $(0, 1)$ — дээш

### 🔵 Cohesion — хөршүүдийн төв рүү

$$
\text{cohesion} = \text{хөршүүдийн дундаж байрлал} - \text{миний байрлал}
$$

Дундаж байрлал $= \left(\frac{2 + 0}{2}, \frac{0 + 2}{2}\right) = (1, 1)$. Миний байрлал $(0, 0)$ тул **cohesion = (1, 1)** → баруун дээш, хөршүүдийн дунд руу.

### 🟢 Alignment — ижил чиглэлд

$$
\text{alignment} = \text{хөршүүдийн дундаж чиглэл}
$$

$\left(\frac{1 + 0}{2}, \frac{0 + 1}{2}\right) = $ **(0.5, 0.5)** → тэдний чиглэлийн "дунд".

### 🔴 Separation — хэт ойрхноос холдох

Хөрш бүрээс **эсрэг** тийш түлхэнэ. Ойр байх тусам хүчтэй (зайн квадратад хуваана):

$$
\text{separation} = \sum \frac{\text{би} - \text{хөрш}}{\text{зай}^2}
$$

- A-аас: $\frac{(0,0) - (2,0)}{2^2} = \frac{(-2, 0)}{4} = (-0.5,\ 0)$
- B-ээс: $\frac{(0,0) - (0,2)}{4} = (0,\ -0.5)$
- Нийлбэр: **(−0.5, −0.5)** → зүүн доош, хоёулангаас нь холдох.

### Нэгтгэх

$$
\text{шинэ чиглэл} = \text{хуучин чиглэл} + w_s \cdot \text{sep} + w_a \cdot \text{ali} + w_c \cdot \text{coh}
$$

$w$ бол "жин" — дүрэм бүр хэр чухал вэ. Demo-ийн гурван гулсуур яг эдгээр жин! Бодит boid-д түлхэлт бүрийг хэт огцом эргэхгүйн тулд хязгаарладаг.

## Demo дээр туршаад үз

- **Alignment**-ийг 0 болго — сүрэг тарна. Буцааж нэмэхэд аажмаар нэг чиглэлд эвлэрнэ.
- **Cohesion** их → нягт бөөгнөрөл. **Separation** их → тархсан, жигд зайтай.
- Хулганаа canvas дээр аваач: **Махчин 🦅** — сүрэг зугтаж хуваагдана, **Хоол 🍞** — цугларна.
- **Нэг boid-ийг задлан харах** — хар boid-ийн хөршүүд ба гурван сум (🔴🟢🔵) харагдана. Дээрх тооцоолол яг тэр сумнууд!
- **Skin**: шувуу 🐦, загас 🐟 — дүрс өөр, дүрэм ижил.

## Нэг санаа авч үлдэх

> **Удирдагчгүй, төлөвлөгөөгүй ч зохион байгуулалт гарч ирж болно.** Загасны сүрэг, хүмүүсийн урсгал, тоглоомын олон нэгж, drone swarm — бүгд энэ санаа.

## Код (C++)

Дээрх жишээний гурван сумыг тооцоолдог бүтэн программ:

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Vec {
    double x = 0, y = 0;
    Vec operator+(Vec o) const { return {x + o.x, y + o.y}; }
    Vec operator-(Vec o) const { return {x - o.x, y - o.y}; }
    Vec operator/(double k) const { return {x / k, y / k}; }
};
struct Boid { Vec pos, vel; };

int main() {
    Boid me{{0, 0}, {0, 0}};
    vector<Boid> neighbours = {{{2, 0}, {1, 0}}, {{0, 2}, {0, 1}}};

    Vec sumPos, sumVel, separation;
    for (const Boid& n : neighbours) {
        sumPos = sumPos + n.pos;
        sumVel = sumVel + n.vel;
        Vec away = me.pos - n.pos;                         // хөршөөс над руу
        double dist2 = away.x * away.x + away.y * away.y;  // зайн квадрат
        separation = separation + away / dist2;
    }
    double k = neighbours.size();
    Vec cohesion  = sumPos / k - me.pos;                   // дундаж байрлал руу
    Vec alignment = sumVel / k;                            // дундаж чиглэл

    cout << "cohesion   = (" << cohesion.x   << ", " << cohesion.y   << ")\n";
    cout << "alignment  = (" << alignment.x  << ", " << alignment.y  << ")\n";
    cout << "separation = (" << separation.x << ", " << separation.y << ")\n";
}
```

Гаралт: `(1, 1)`, `(0.5, 0.5)`, `(-0.5, -0.5)` — дээрх гар тооцоололтой яг ижил. Demo-ийн бүтэн код: [demo.js](demo.js).
