Аниматор мянган сарьсан багваахай бүрийг гараар хөдөлгөх шаардлагагүй — гурван дүрэм хангалттай. Reynolds энэ ажлаараа 1998 онд Academy-ийн шинжлэх ухаан, техникийн шагнал хүртсэн.

### Олон түмний тулаан

**The Lord of the Rings**-ийн мянга мянган дайчинтай тулаан **MASSIVE** программаар бүтсэн: дайчин бүр өөрийн "тархи"-тай agent бөгөөд хөршөө хараад шийдвэр гаргана. Энэ бол boids-ийн өргөтгөсөн санаа — agent-based crowd simulation.

## 🎮 Game development

### Амьд ертөнц: шувуу, загас, амьтан

Open-world тоглоомуудын тэнгэрт нисэх шувуу, усанд сэлэх загасны сүрэг, тал нутгийн амьтдын сүрэг нь ихэвчлэн boids-ийн хувилбар. Тоглогч ойртоход сүрэг сарних нь demo дахь **Махчин 🦅** горимтой яг ижил.

### RTS нэгжүүдийн хөдөлгөөн

Strategy тоглоомд 50 нэгжийг нэг цэг рүү илгээхэд бүгд нэг нүдэнд бөөгнөрөхгүй байх ёстой. Тиймээс pathfinding (хаашаа явах)-ийн дээр boids маягийн **steering** (хэрхэн явах) нэмдэг:

- **Separation** — нэгжүүд бие биенээ түлхэж, давхцахгүй
- **Alignment / Cohesion** — бөөнөөрөө нэг хурдаар хөдлөх

StarCraft II зэрэг тоглоомын нэгжүүд бие биенээ зөөлөн түлхэж, урсгал мэт хөдөлдөг нь ийм steering-ийн жишээ.

**Өөрөө туршиж үз** — 24 нэгжийг нэг цэг рүү илгээ. Separation-ийг унтраавал бүгд нэг цэгт давхцана:

### Zombie horde, дайсны сүрэг

Олон зуун zombie нэг дор гүйдэг тоглоомууд бүгдэд нь A* ажиллуулах боломжгүй — цөөн "удирдагч" зам хайж, бусад нь boids-оор түүнийг дагана.

```csharp
// Unity: boid бүрийн steering — demo-той яг ижил гурван дүрэм.
Vector3 Steer(Boid b, List<Boid> near) {
    Vector3 sep = Vector3.zero, ali = Vector3.zero, coh = Vector3.zero;
    foreach (var o in near) {
        Vector3 d = o.pos - b.pos;
        sep -= d / d.sqrMagnitude;     // ойр байх тусам хүчтэй түлхэнэ
        ali += o.vel;
        coh += d;
    }
    int n = near.Count;
    return wSep * Limit(sep.normalized * maxSpeed - b.vel)
         + wAli * Limit((ali / n).normalized * maxSpeed - b.vel)
         + wCoh * Limit((coh / n).normalized * maxSpeed - b.vel);
}
```

## 🖥️ Технологи ба шинжлэх ухаан

### Drone swarm

2018 онд Унгарын судлаачид 30 drone-ийг төв удирдлагагүйгээр задгай агаарт **сүрэглэн** нисгэж чадсан (*Science Robotics*) — drone бүр зөвхөн хөршүүдийнхээ байрлал, хурдыг мэддэг, яг boids шиг. Харин баярын **drone light show**-ууд ихэнхдээ урьдчилан программчилсан замаар нисдэг — тэнд "сүрэг" биш, "бүжиг дэглэлт".

### Particle Swarm Optimization (PSO)

1995 онд Kennedy, Eberhart нар шувууны сүргээс санаа авч **PSO** optimization algorithm зохиосон: "particle" бүр шийдлийн орон зайд нисэж, өөрийн болон хөршүүдийнхээ олсон хамгийн сайн цэг рүү татагдана. Neural network-ийн параметр, инженерийн дизайн, антенны хэлбэр тохируулахад хэрэглэгддэг.

### Хүмүүсийн урсгал ба аюулгүй байдал

Барилга, цэнгэлдэх хүрээлэн, метроны буудал зураглахдаа яаралтай гарах үеийн хүмүүсийн урсгалыг agent simulation-аар шалгадаг (Helbing-ийн **social force model**): хүн бүр зорьсон газар руугаа явахын зэрэгцээ бусдаас зай барина — separation-тай ижил. Хаалганы өргөн, баганын байрлал түгжрэл үүсгэх эсэхийг урьдчилан хардаг.
