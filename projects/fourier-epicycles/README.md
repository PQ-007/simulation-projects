# Fourier Epicycles

Энэ demo-д эргэлдэж буй тойргууд зүрх, од, бүр лого зурдаг. Гэхдээ үүнийг ойлгохын тулд эхлээд нэг гайхалтай санааг мэдэх хэрэгтэй: **Fourier series**. Алхам алхмаар, тэгээс нь эхэлье.

## 1. Долгион гэж юу вэ?

Дугуй (жишээ нь чөтгөрийн дугуй) эргэж байна гэж төсөөл. Дугуйн ирмэг дээрх нэг цэгийн **өндрийг** цаг хугацааны дагуу зурвал юу гарах вэ?

- Эхэндээ төв түвшинд (өндөр **0**)
- Дөрөвний нэг эргэхэд хамгийн дээр (**1**)
- Хагас эргэхэд дахиад төв түвшинд (**0**)
- Дөрөвний гурав эргэхэд хамгийн доор (**−1**)
- Бүтэн эргэхэд эхэнд нь буцаж ирнэ

Энэ гөлгөр дээш доош хэлбэлзлийг **sine долгион** гэдэг. Томьёогоор:

$$
\text{өндөр} = \sin(t)
$$

$t$ = дугуй хэр эргэсэн (өнцөг).

| Эргэлт $t$ | 0° | 30° | 90° | 180° | 270° | 360° |
| --- | --- | --- | --- | --- | --- | --- |
| $\sin(t)$ | 0 | 0.5 | **1** | 0 | **−1** | 0 |

> **Нэг sine долгион = нэг эргэлдэх тойргийн "сүүдэр".**

## 2. Хурд ба хэмжээ

Долгион бүрт хоёр л тохиргоо бий:

| Бичлэг | Утга | Жишээ |
| --- | --- | --- |
| $\sin(3t)$ | **3 дахин хурдан** эргэнэ | Нэг эргэлтийн хугацаанд 3 удаа дээш доош |
| $\tfrac{1}{3}\sin(t)$ | **3 дахин жижиг** тойрог | Хамгийн өндөр нь 1 биш, ⅓ |
| $\tfrac{1}{3}\sin(3t)$ | хоёулаа | Жижиг, хурдан чичиргээ |

Хурдыг **давтамж** (frequency), хэмжээг **далайц** (amplitude) гэдэг.

## 3. Долгионуудыг нэмэх — гол санаа

Хоёр долгионыг **нэмэхэд** цэг бүр дээр өндрүүдийг нь нэмнэ. Тэгэхэд **шинэ хэлбэр** гарна!

**Жишээ:** $\sin(t) + \tfrac{1}{3}\sin(3t)$-ийг $t = 90°$ дээр бодъё:

- $\sin(90°) = 1$
- $\tfrac{1}{3}\sin(3 \cdot 90°) = \tfrac{1}{3}\sin(270°) = \tfrac{1}{3} \cdot (-1) = -0.33$
- Нийлбэр: $1 - 0.33 = 0.67$

Хурдан жижиг долгион том долгионы **оройг дарж хавтгай** болгож байна! Ингээд хурдан, жижиг долгионуудыг нэмсээр байвал... **дөрвөлжин** долгион гарна:

$$
\text{дөрвөлжин} \approx \frac{4}{\pi}\left[\sin(t) + \tfrac{1}{3}\sin(3t) + \tfrac{1}{5}\sin(5t) + \tfrac{1}{7}\sin(7t) + \dots\right]
$$

Дөрвөлжин долгион $t = 90°$ дээр яг **1** байх ёстой. Долгион нэмэх бүрт хэр ойртохыг хар:

| Долгионы тоо | 1 | 2 | 3 | 4 | 5 | … | олон |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Утга ($t = 90°$) | 1.27 | 0.85 | 1.10 | 0.92 | 1.06 | … | → **1** |

Дээш доош савлаж байгаад **1 рүү ойртож** байна!

**Өөрөө туршаад үз** — "Долгионы тоо"-г 1-ээс аажмаар өсгө. Өнгөт нимгэн долгионууд (тус бүр нэг sine) нийлж, хар зузаан шугам (нийлбэр) дөрвөлжин болж байгааг хар:

## 4. Fourier series — "жор"

Joseph Fourier 1807 онд гайхалтай зүйл нээсэн:

> **Ямар ч давтагддаг хэлбэрийг sine долгионуудын нийлбэрээр гаргаж болно.**

$$
f(t) = a_1 \sin(t) + a_2 \sin(2t) + a_3 \sin(3t) + \dots
$$

Үүнийг **жор** гэж бод. Smoothie хийхэд гадил, гүзээлзгэнэ, сүү хэдэн аяга орох вэ гэдэг шиг:

| Smoothie | Fourier series |
| --- | --- |
| Орц (гадил, гүзээлзгэнэ…) | Sine долгионууд: $\sin(t), \sin(2t), \sin(3t)…$ |
| Хэмжээ (2 аяга, ½ аяга…) | Коэффициент: $a_1, a_2, a_3…$ |
| Бэлэн smoothie | Таны хэлбэр $f(t)$ |

**Дөрвөлжин долгионы жор:** $a_1 = 1,\ a_3 = \tfrac{1}{3},\ a_5 = \tfrac{1}{5}$… (тэгш дугаартай нь 0), бүгдийг $\tfrac{4}{\pi}$-ээр үржүүлнэ.

**Fourier transform** бол эсрэг ажил: бэлэн smoothie-г амсаад жорыг нь олох. Хэлбэрийг өгөхөд "энд $\sin(3t)$ хэр их, $\sin(5t)$ хэр их байна" гэж тооцоолно.

### Жорыг яаж олдог вэ?

Хэлбэрт $\sin(3t)$ хэр их байгааг мэдэхийн тулд хэлбэрийг $\sin(3t)$-ээр **үржүүлээд дундажлана**:

- Хэлбэрт $\sin(3t)$ байвал тэд **ижил хэмнэлээр** дээш доош хөдөлнө → үржвэр нь ихэвчлэн эерэг → дундаж **том**.
- Байхгүй бол хэмнэл нь таарахгүй, үржвэр нь заримдаа эерэг, заримдаа сөрөг → бие биенээ устгаад дундаж **≈ 0**.

Радиогоо нэг станц руу тааруулахтай адил: зөвхөн тэр давтамжтай "резонанс" өгнө.

## 5. Долгионоос тойрог руу

1-р хэсэгт sine долгион бол **эргэлдэх тойргийн сүүдэр** гэж хэлсэн. Тэгэхээр Fourier series-ийн долгион бүр нь нэг тойрог:

- $\tfrac{1}{3}\sin(3t)$ = радиус нь ⅓, 3 дахин хурдан эргэх тойрог.

Тойргуудыг нэгнийх нь **үзүүрт** нөгөөг нь залгаж (дугуйн дээр дугуй, түүн дээр дахиад дугуй…) эргүүлбэл хамгийн сүүлчийн үзүүрийн өндөр нь бүх долгионы **нийлбэр**. Дээрх widget-ийн зүүн тал яг үүнийг харуулж байна — эдгээр тойргийг **epicycle** гэдэг.

## 6. Зураг руу — энэ demo

Одоо том алхам. Дээр бид зөвхөн **өндрийг** (дээш доош) харсан. Харин зураг зурахад **хоёр** чиглэл хэрэгтэй: баруун-зүүн (**x**), дээш-доош (**y**).

Тойргийн үзүүр хоёуланг нь зэрэг хөдөлгөдөг! Тиймээс:

1. Дүрсийн хүрээг олон цэг болгоно (зүрхийг тойрон 1024 цэг).
2. Fourier transform "энэ дүрсийн жор юу вэ" гэж олно: ямар хэмжээтэй, ямар хурдтай тойргууд хэрэгтэй.
3. Тойргуудыг томоос нь жижиг рүү залгаж эргүүлэхэд хамгийн сүүлийн үзүүр **дүрсийг зурна**.

Цэг бүрийг $(x, y)$ гэж хадгалахын тулд математикчид **комплекс тоо** хэрэглэдэг — энэ бол зүгээр л "хоёр тоог нэг дор хадгалах" арга. Тойргийн жорыг олох томьёо:

$$
c_k = \frac{1}{N} \sum_{n=0}^{N-1} z_n \cdot e^{-2\pi i k n / N}
$$

Айх хэрэггүй — энэ бол 4-р хэсгийн **"үржүүлээд дундажлах"** яг тэр санаа:

- $z_n$ — дүрсийн $n$-р цэг
- $e^{-2\pi i k n / N}$ — "$k$ хурдаар эсрэг тийш эргүүл" (тойрог дээрх цэг)
- $\frac{1}{N}\sum$ — бүгдийн **дундаж**
- $c_k$ — $k$ хурдтай тойргийн **хэмжээ ба эхлэх өнцөг**

**Жишээ.** Дүрс нь ердөө 4 цэгтэй тойрог: $(1,0) \to (0,1) \to (-1,0) \to (0,-1)$.

- $k = 1$ (1 хурдтай тойрог): цэг бүрийг өөрийнхөө өнцгөөр буцааж эргүүлэхэд **бүгд** $(1, 0)$ болно → дундаж $(1, 0)$ → **хэмжээ 1** ✓
- $k = 2$: хоёр дахин эргүүлэхэд $(1,0), (-1,0), (1,0), (-1,0)$ → бие биенээ устгана → **хэмжээ 0**.

Тэгэхээр энэ дүрсийн жор = **ганц тойрог**. Зөв!

## Код (C++)

**1. Fourier series** — дөрвөлжин долгионыг $t = 90°$ дээр 1-ээс 5 долгионоор бодож, дээрх хүснэгтийг хэвлэнэ:

```cpp
#include <cmath>
#include <cstdio>

int main() {
    double t = M_PI / 2;                          // 90°
    double sum = 0;
    for (int k = 1; k <= 5; k++) {
        int n = 2 * k - 1;                        // зөвхөн сондгой: 1, 3, 5, 7, 9
        sum += (4 / M_PI) * std::sin(n * t) / n;  // 4/π · (1/n) · sin(n·t)
        std::printf("%d долгион: %.2f\n", k, sum);
    }
}
```

**2. Fourier transform** — 4 цэгтэй тойргийн жорыг олно (`std::complex` = цэгийг $x + iy$ гэж хадгалах):

```cpp
#include <complex>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <vector>
using namespace std;
using Point = complex<double>;               // (x, y) цэг

int main() {
    vector<Point> z = {{1, 0}, {0, 1}, {-1, 0}, {0, -1}};   // нэг удаа тойрох
    int N = z.size();
    for (int k = 0; k < N; k++) {
        Point sum = 0;
        for (int n = 0; n < N; n++) {
            double angle = -2 * M_PI * k * n / N;          // эсрэг тийш эргүүлэх
            sum += z[n] * polar(1.0, angle);               // polar = e^{i·angle}
        }
        Point c = sum / double(N);                         // дундаж
        cout << "k = " << k << ": тойргийн хэмжээ = " << fixed << setprecision(2) << abs(c) << "\n";
    }
}
```

Гаралт: эхнийх нь `1.27, 0.85, 1.10, 0.92, 1.06`; хоёр дахь нь зөвхөн `k = 1` дээр `1.00`. Demo-ийн бүтэн код: [demo.js](demo.js), widget: [series.js](series.js).
