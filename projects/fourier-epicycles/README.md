# Fourier Epicycles

Ямар ч битүү муруйг эргэлдэж буй тойргуудын (epicycle) гинжээр дахин зурж болно. Дүрс зураад, тойргууд түүнийг хэрхэн давтан зурж байгааг ажиглаарай.

## Санаа

Замын цэг бүрийг $z_n = x_n + i\,y_n$ комплекс тоо гэж үзье. Discrete Fourier Transform (DFT) замыг эргэлдэх векторуудад задална:

$$
c_k = \frac{1}{N} \sum_{n=0}^{N-1} z_n \, e^{-2\pi i k n / N}
$$

Эдгээр коэффициентоос замыг буцаан сэргээнэ:

$$
z(t) = \sum_{k} c_k \, e^{i k t}, \qquad t \in [0, 2\pi)
$$

$c_k$ гишүүн бүр нь $|c_k|$ радиустай, $k$ давтамжаар эргэлдэж, $\arg(c_k)$ өнцгөөс эхэлдэг тойрог юм. Тэдгээрийг үзүүр үзүүрээр нь залгахад хамгийн сүүлчийн үзүүр анхны замыг зурна.

## Хэрхэн ашиглах

- **Зурах:** canvas дээр хулгана эсвэл хуруугаа чирж битүү дүрс зурна.
- **Тойрог:** хэдэн тойрог ашиглахыг сонгоно. Цөөн тойрогтой үед гөлгөр, олон тойрогтой үед нарийн дүрс гарна.
- **Хурд**, **Зогсоох**, **Тойргийг харуулах** нь хөдөлгөөнийг удирдана.
- **Shape:** бэлэн дүрсүүд. Энгийн (Зүрх, Од, Дөрвөлжин)-ээс гадна олон тойрог шаарддаг нарийн муруйнууд бий:
  - **Butterfly** — Temple Fay-ийн муруй, $r = e^{\cos t} - 2\cos 4t - \sin^5(t/12)$.
  - **Spirograph** — hypotrochoid ($R=10,\ r=7,\ d=5$), 7 эргэлтийн дараа битүүрнэ.
  - **Rose** — $r = \cos(7t/4)$, 14 дэлбээтэй.
  - **Lissajous** — $x = \sin(5t + \pi/2),\ y = \sin 4t$.
- **Текст / тэмдэгт:** дурын үсэг, тэмдэгт, үг бичээд (жишээ нь π, Ф, 8, Сайн) түүний контурыг зуруулна. Тойргийн тоог багасгахад нарийн хэсгүүд хамгийн түрүүнд алга болдгийг ажиглаарай.

## Код

DFT-г шууд томьёогоор нь, $O(N^2)$ хугацаанд тооцоолно. $e^{-i\theta} = \cos\theta - i\sin\theta$ гэдгийг ашиглан бодит ба хуурмаг хэсгийг тусад нь нэмнэ. $e^{-2\pi i kn/N}$ нь зөвхөн $kn \bmod N$-ээс хамаардаг тул $\cos$, $\sin$-ийг нэг удаа table болгон бодно ($N = 1024$ үед ~10ms):

```js
function dft(pts) {
  const N = pts.length, out = [];
  const cos = Float64Array.from({ length: N }, (_, j) => Math.cos((2 * Math.PI * j) / N));
  const sin = Float64Array.from({ length: N }, (_, j) => Math.sin((2 * Math.PI * j) / N));
  for (let k = 0; k < N; k++) {
    let re = 0, im = 0;
    for (let n = 0, j = 0; n < N; n++, j = (j + k) % N) {
      re += pts[n].x * cos[j] + pts[n].y * sin[j];
      im += pts[n].y * cos[j] - pts[n].x * sin[j];
    }
    re /= N; im /= N;
    const freq = k <= N / 2 ? k : k - N; // сөрөг давтамж = эсрэг чиглэлд эргэнэ
    out.push({ freq, amp: Math.hypot(re, im), phase: Math.atan2(im, re) });
  }
  return out.sort((a, b) => b.amp - a.amp);
}
```

Frame бүрт тойргуудыг гинжлэн, сүүлчийн үзүүрийн байрлалыг олно:

```js
let x = 0, y = 0;
for (const c of coeffs) {
  const a = c.freq * time + c.phase;
  x += c.amp * Math.cos(a);
  y += c.amp * Math.sin(a);
}
trail.push({ x, y });
```

## Хэрэгжүүлэлт

- Энгийн JavaScript ба canvas, гадны library ашиглаагүй ([demo.js](demo.js)).
- Зурсан замыг 1024 жигд зайтай цэг болгон resample хийж, төвд нь шилжүүлээд DFT тооцоолно.
- Текстийг нууц canvas дээр зурж, пиксел бүрийг шалгаад үсэг болон доторх нүх бүрийн хүрээг Moore-neighbor tracing-ээр мөшгинө. Дараа нь контуруудыг хамгийн ойрхон үзүүрээр нь залгаж нэг зам болгоно.
- Logo-г мөн адил мөшгинө: бараан дэвсгэрээс гэрэлтэй пикселүүдийг ялгаж, контур бүрийг moving average-ээр гөлгөржүүлээд хамгийн тод пикселүүдийнх нь дундаж өнгийг авна. Контур хоорондын үсрэлтүүдийг бүдэг шугамаар зурна.
- Frame бүрт хэд хэдэн sub-step бодож trail-д нэмдэг тул хурдан хөдөлгөөнтэй үед ч нарийн хэсгүүд алдагдахгүй.
- Тойргуудыг радиусаар нь эрэмбэлдэг тул **Тойрог** slider хамгийн том тойргуудыг түрүүлж үлдээнэ.
