# Бодит хэрэглээ: Fourier transform

Demo дээр тойрог бүр нэг **давтамж** байсан. Цөөн тойрогтой үед дүрс гөлгөр, олон тойрогтой үед нарийн болж байсныг санаарай. Яг энэ санаа — **дохиог давтамжуудад задлаад, чухал биш давтамжуудыг хаях** — таны утас, чихэвч, Wi‑Fi, тоглоом бүрт ажиллаж байна.

## 🖥️ Технологи

### JPEG зураг ба MP3 дуу — шахалт

- **JPEG** зургийг 8 × 8 блок болгож, блок бүрд Fourier-ийн "үеэл" болох **DCT** (Discrete Cosine Transform) хийнэ. Нүдэнд бараг үл анзаарагдах өндөр давтамжуудыг (нарийн хэсэг) бүдүүвчлэн хадгалж, файлыг 10 дахин багасгана. JPEG-ийн "quality" гулсуур = demo дахь **тойргийн тоо**.
- **MP3, AAC** дуу ч мөн адил (MDCT): хүний чих сонсохгүй давтамжуудыг хаядаг.

**Өөрөө туршиж үз** — доорх зургийг жинхэнэ 8 × 8 DCT-ээр шахаж байна. Коэффициентийг багасгахад JPEG-ийн «блок» алдаа гарч ирнэ:

### Shazam — дууг таних

Shazam дууг **spectrogram** (цаг хугацааны дагуух давтамжийн зураг) болгоод, хамгийн хүчтэй цэгүүдийн "одны зураг"-аар хурууны хээ (fingerprint) үүсгэнэ. Кафены шуугиан дунд ч хэдхэн секундэд таньдаг нь давтамжийн оргилууд дуу чимээнд тэсвэртэй учраас.

### Wi‑Fi, 4G, 5G — OFDM

Орчин үеийн утасгүй холбоо **OFDM** ашигладаг: өгөгдлийг олон зуун жижиг давтамж (subcarrier) дээр зэрэг илгээнэ. Илгээгч нь **inverse FFT**-ээр давтамжуудыг нэг дохио болгож, хүлээн авагч нь **FFT**-ээр буцааж задлана — яг demo дахь тойргуудыг нийлүүлэх, задлах хоёр.

### MRI — эмнэлгийн зураг

MRI аппарат биеийн зургийг шууд авдаггүй — давтамжийн өгөгдөл (**k-space**) хэмждэг. Компьютер **inverse Fourier transform** хийж байж зураг гарна.

### Дууны equalizer ба visualizer

Хөгжим тоглуулагчийн bass/treble тохиргоо нь тодорхой давтамжийн бүсийг өсгөж, багасгадаг. Хөгжимд хөдөлдөг баганан visualizer нь FFT-ийн үр дүнг шууд зурдаг. Browser-т үүнийг хэдхэн мөрөөр хийж болно:

```js
const ctx = new AudioContext();
const analyser = ctx.createAnalyser();
analyser.fftSize = 256;                          // 128 давтамжийн багана
ctx.createMediaElementSource(audioEl).connect(analyser);
analyser.connect(ctx.destination);

const bins = new Uint8Array(analyser.frequencyBinCount);
function frame() {
  analyser.getByteFrequencyData(bins);           // browser FFT хийнэ
  bins.forEach((v, i) => drawBar(i, v));         // bins[0] = bass ... bins[127] = treble
  requestAnimationFrame(frame);
}
```

## 🎮 Game development

### Далайн давалгаа

- **FFT ocean** (Jerry Tessendorf, "Simulating Ocean Water"): далайн гадаргууг мянга мянган давалгааны **давтамжийн спектр**-ээр тодорхойлж, frame бүрт inverse FFT-ээр өндрийн зураг гаргана. Кино, AAA тоглоомын далай ихэвчлэн ийм аргатай.
- Энгийн хувилбар нь хэдэн **Gerstner wave** (синусын давалгаа)-г нийлүүлэх — Unreal Engine-ийн Water system ийм. Энэ бол яг demo дахь "хэдэн тойргийг нийлүүлж дүрс гаргах" санаа.

@youtube(PH9q0HNBjT4 "Acerola: How Games Fake Water — синус давалгаанаас FFT ocean хүртэл")

### Хэмнэлийн тоглоом ба дуунд хариу үйлдэл

Rhythm game, дуунд хөдөлдөг гэрэл, эффект нь FFT-ээр bass-ийн энергийг хэмжиж **beat** илрүүлдэг: бага давтамжийн энерги огцом өсвөл — бөмбөр цохисон.

### Хэлбэр таних

Гараар зурсан дүрсийг таних (жишээ нь шившлэгийн тэмдэг зурдаг тоглоом)-д **Fourier descriptor** хэрэглэдэг: дүрсийн контурыг яг demo шиг DFT хийж, эхний хэдэн коэффициентийг харьцуулна. Том тойргууд хэлбэрийг, жижиг нь нарийн хэсгийг илэрхийлдэг тул хэмжээ, эргэлтээс үл хамааран таньж чадна.

## Онол ↔ Бодит амьдрал

| Demo дахь ойлголт | Бодит хэрэглээ |
| --- | --- |
| Тойрог = нэг давтамж $c_k$ | Spectrogram-ийн нэг мөр, Wi‑Fi-ийн нэг subcarrier |
| Тойргийн тоог багасгах | JPEG/MP3 шахалт, noise арилгах |
| Тойргуудыг нийлүүлж дүрс зурах (inverse) | OFDM илгээгч, MRI, FFT ocean |
| Дүрсийг тойрогт задлах (DFT) | Shazam, equalizer, visualizer, хэлбэр таних |
| $O(N^2)$ DFT → $O(N \log N)$ FFT | Бүгд бодит хугацаанд ажиллах шалтгаан |
