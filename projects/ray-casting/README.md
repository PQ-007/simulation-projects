# Ray Casting

1992 онд **Wolfenstein 3D** тоглоом тухайн үеийн сул компьютер дээр "3D" ертөнц харуулж бүгдийг гайхшруулсан. Нууц нь: ертөнц үнэндээ **хавтгай 2D газрын зураг**, харин дэлгэцийг маш ухаалаг аргаар зурдаг.

## Энгийнээр хэлбэл

Харанхуй өрөөнд гар чийдэн барьж зогсож байна гэж төсөөл. Чийдэнгээ зүүнээс баруун тийш аажмаар эргүүлж, гэрэл хана хүртэл **хэр хол** явж байгааг хэмжинэ:

- Хана **ойрхон** → дэлгэц дээр **өндөр** зурна.
- Хана **хол** → **намхан** зурна.

Дэлгэцийн **босоо багана бүрт нэг "туяа"** (ray) шидээд, хана хүртэлх зайгаар баганын өндрийг тодорхойлно. Олон баганыг зэрэгцүүлэхэд 3D өрөө харагдана — гэтэл бүх зүйл 2D!

## Томьёо — алхам алхмаар

### 1. Хананы өндөр

$$
\text{баганын өндөр} = \frac{\text{дэлгэцийн өндөр}}{\text{зай}}
$$

**Жишээ:** дэлгэц 600 пиксел өндөр.

| Хана хүртэлх зай | Баганын өндөр |
| --- | --- |
| 1 нүд | 600 / 1 = **600** px — бүтэн дэлгэц |
| 2 нүд | 600 / 2 = **300** px |
| 4 нүд | 600 / 4 = **150** px |

Хоёр дахин хол → хоёр дахин жижиг. Бодит амьдралд ч яг ийм: хол байгаа зүйл жижиг харагддаг.

### 2. Нүд нүдээр алхах (DDA)

Туяа жижиг алхмаар биш, зөвхөн **нүдний хил дээр** "үсэрнэ". Туяаны чиглэл $(d_x, d_y)$ бол нэг нүдийг хэвтээ чиглэлд туулахад:

$$
\text{нэг нүд туулах зай} = \left|\frac{1}{d_x}\right|
$$

**Жишээ:** туяа баруун тийш $d_x = 0.5$ хурдтай бол нэг нүдийг туулахад $1 / 0.5 = 2$ зай явна. Хэвтээ, босоо хилийн аль нь **ойр** байна, тэр рүү үсэрч, хана хүртэл давтана.

### 3. Fisheye-ийн засвар

Дэлгэцийн захын туяа хажуу тийш хазгай явдаг тул арай **урт**. Шулуун хана муруй харагдана. Засвар нь туяаны өнцөг $\theta$-ээр үржих:

$$
d_{\text{зөв}} = d \cdot \cos\theta
$$

**Жишээ:** урдах шулуун хана 4 нүд зайтай. Дунд багана ($\theta = 0°$) 4 гэж хэмжинэ. Захын багана ($\theta = 30°$) хазгай явж $4 / \cos 30° \approx 4.62$ гэж хэмжинэ → **130** px (дунд нь 150) → хана муруй! Засвар: $4.62 \cdot \cos 30° = 4$ → **150** px → шулуун ✓

## Demo дээр туршаад үз

- **WASD** эсвэл сумаар алх, 3D дээр чирж эргэ.
- 3D дэлгэц дээр хулганаа хөдөлгө — тухайн баганын туяа газрын зураг дээр **шараар** тодорч, зай нь бичигдэнэ.
- **Ray-ийн тоо**-г 8 болго — дэлгэц 8 өргөн зурвас болно. "1 туяа = 1 багана"!
- **Fisheye (засваргүй)**-г асааж дээрх муруйлтыг өөрийн нүдээр хар.
- Газрын зураг дээр дарж **хана нэм / хас**.

## Нэг санаа авч үлдэх

> **"3D" бол заримдаа ухаалаг хуурмаг.** "Туяа шидээд юу мөргөхийг хар" санаа өнөөдөр ч буудлага, RTX график, Pixar-ийн кино, LIDAR-д ажилладаг.

## Код (C++)

Терминал дээр жижиг "3D" дүр зураг тэмдэгтээр зурдаг бүтэн ray caster:

```cpp
#include <cmath>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<string> map = {
    "##########",
    "#........#",
    "#..##....#",
    "#........#",
    "#.....#..#",
    "#........#",
    "##########",
};

// DDA: туяаг нүдний хилээс хил рүү үсрүүлж, хана хүртэлх зайг буцаана
double castRay(double px, double py, double dx, double dy) {
    int mx = px, my = py;
    double stepX = fabs(1 / dx), stepY = fabs(1 / dy);      // нэг нүд туулах зай
    int sx = dx < 0 ? -1 : 1, sy = dy < 0 ? -1 : 1;
    double nextX = (dx < 0 ? px - mx : mx + 1 - px) * stepX;
    double nextY = (dy < 0 ? py - my : my + 1 - py) * stepY;
    while (true) {
        if (nextX < nextY) { mx += sx; if (map[my][mx] == '#') return nextX; nextX += stepX; }
        else               { my += sy; if (map[my][mx] == '#') return nextY; nextY += stepY; }
    }
}

int main() {
    const int W = 60, H = 20;
    double px = 2.5, py = 5.5, angle = -0.6, fov = 1.1;          // тоглогч
    double dirX = cos(angle), dirY = sin(angle);
    double planeX = -dirY * tan(fov / 2), planeY = dirX * tan(fov / 2);

    vector<string> screen(H, string(W, ' '));
    for (int y = H / 2; y < H; y++) screen[y] = string(W, '.');     // шал
    for (int col = 0; col < W; col++) {
        double side = 2.0 * col / W - 1;                          // -1 (зүүн) … 1 (баруун)
        double dist = castRay(px, py, dirX + planeX * side, dirY + planeY * side);
        int height = min(H, int(H / dist));                       // өндөр = дэлгэц / зай
        char shade = dist < 2 ? '#' : dist < 4 ? '=' : '-';       // хол = бүдэг
        for (int y = (H - height) / 2; y < (H + height) / 2; y++) screen[y][col] = shade;
    }
    for (auto& row : screen) cout << row << "\n";
}
```

Туяаны чиглэл `dir + plane * side` хэлбэртэй тул `castRay`-ийн буцаах зай аль хэдийн fisheye-гүй (зөв) зай байдаг. Demo-ийн бүтэн код: [demo.js](demo.js).
