# Noise Visualizer

> Fourier series-ийг (долгионуудыг нэмж хэлбэр гаргах) мэдэхгүй бол эхлээд **Fourier Epicycles** project-ийн **Docs**-ийг уншаарай — энэ demo яг тэр санаан дээр ажилладаг.

Дуу гэж юу вэ? Агаарын маш хурдан **чичиргээ**. Микрофон тэр чичиргээг секундэд 48 000 удаа хэмжиж тоо болгодог. Энэ demo тэр тоонуудыг **гурван өөр нүдээр** харуулна.

## Энгийнээр хэлбэл

Хөгжмийн хамтлаг төсөөл: бөмбөр, басс, хоолой, хуур... Бүгд зэрэг тоглоход чихэнд нэг л "дуу" сонсогдоно. Гэтэл тархи тань тэдгээрийг ялгаж чадна. Компьютер ч ялгаж чадна — **FFT** (Fourier transform-ийн хурдан хувилбар)-ийн тусламжтай.

| Цонх | Юуг харуулна | Төсөөлөл |
| --- | --- | --- |
| **Waveform** | Чичиргээ цаг хугацааны дагуу | Далайн давалгааг хажуунаас харах |
| **Spectrum** | Яг одоо ямар **давтамж** хэр чанга | Хамтлагийн аль хөгжим хэр чанга тоглож байна |
| **Spectrogram** | Давтамжууд цаг хугацааны дагуу | Нот бичиг шиг — зүүнээс баруун тийш урсана |

## Томьёо — алхам алхмаар

### 1. Давтамж — секундэд хэдэн удаа?

**Давтамж** $f$ (Hz) = секундэд хэдэн удаа чичирхийлэх вэ. **Жишээ:** 440 Hz = агаар секундэд **440** удаа нааш цааш хөдөлнө. Бага давтамж = бүдүүн дуу (басс), өндөр = нарийн (исгэрээ).

### 2. Нот — давтамжийг хөгжмийн нэр болгох

$$
m = 69 + 12 \cdot \log_2 \frac{f}{440}
$$

$\log_2$ гэдэг нь *"2-ыг хэдэн удаа үржүүлбэл тэр тоо гарах вэ"*. $\log_2 2 = 1$, $\log_2 4 = 2$, $\log_2 1 = 0$.

| Давтамж $f$ | $f / 440$ | $\log_2$ | $m$ | Нот |
| --- | --- | --- | --- | --- |
| 440 Hz | 1 | 0 | $69 + 0 = 69$ | **A4** (Ла) |
| 880 Hz | 2 | 1 | $69 + 12 = 81$ | **A5** — нэг октав дээш |
| 220 Hz | 0.5 | −1 | $69 - 12 = 57$ | **A3** — нэг октав доош |

Давтамж **2 дахин** өсөх = **12 нот** (нэг октав) дээш. Төгөлдөр хуурын 12 товч (7 цагаан + 5 хар) яг нэг октав.

### 3. FFT-ийн "шугам" — давтамжийн нарийвчлал

FFT дууг тусдаа давтамжийн "сав"-нд хуваана. Савны өргөн:

$$
\text{савны өргөн} = \frac{\text{секундэд хэмжих тоо}}{\text{нэг удаа авах хэмжилт}} = \frac{48000}{4096} \approx 11.7 \text{ Hz}
$$

Захирагч дээрх шугам шиг: 11.7 Hz-ээс нарийн ялгааг шууд харж чадахгүй. Demo оргилын хажуугийн савнуудаас илүү нарийн тооцоолдог.

### 4. Децибел (dB) — хэр чанга вэ

$$
L = 20 \cdot \log_{10} \frac{A}{A_0}
$$

Үгээр: *"өөр дуунаас хэдэн дахин хүчтэй вэ"*. **Жишээ:** 2 дахин хүчтэй долгион → $20 \cdot \log_{10} 2 \approx +6$ dB. 10 дахин → $+20$ dB. Pink noise-д октав бүрт **−3 dB**, brown-д **−6 dB** гэсэн нь "дээшлэх тусам сулардаг" гэсэн үг.

## Demo дээр туршаад үз

- **Sine** — Spectrum дээр **ганц оргил**. **Давтамж**-ийг гулсуулж оргил хөдлөхийг, нот солигдохыг хар (440 Hz = A4).
- **Аккорд 🎹** — Waveform эмх замбараагүй ч Spectrum дээр **гурван оргил** (C, E, G). FFT тэднийг салгав!
- **Chirp ↗** — Spectrogram дээр дээш гулсах шугам.
- **White / Pink / Brown noise** — бүх давтамжийн холимог; налуу нь өөр.
- **🎤 Микрофон** — "А", "И", "У" гэж хэлэхэд Spectrogram хэрхэн өөр вэ?
- **Lowpass** filter — өндөр давтамжууд алга болж, дуу "бүдэг" болно.

## Нэг санаа авч үлдэх

> **Дуу бол олон энгийн долгионы нийлбэр, FFT түүнийг буцааж салгадаг.** Shazam, гитар тааруулагч, Auto-Tune, MP3, "Hey Siri" — бүгд эхлээд дууг давтамжид задалдаг.

## Код (C++)

440 Hz дуу үүсгээд, DFT-ээр давтамжийг нь олж, нотыг хэвлэдэг бүтэн программ:

```cpp
#include <cmath>
#include <complex>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    const double rate = 8000;                  // секундэд 8000 хэмжилт
    const int N = 2048;                        // нэг удаа 2048 хэмжилт
    vector<double> sound(N);
    for (int n = 0; n < N; n++) sound[n] = sin(2 * M_PI * 440 * n / rate);   // 440 Hz

    // DFT: сав бүрт "энэ давтамж хэр их байна" (энгийн, удаан хувилбар)
    int best = 0; double bestPower = 0;
    for (int k = 1; k < N / 2; k++) {
        complex<double> sum = 0;
        for (int n = 0; n < N; n++) sum += sound[n] * polar(1.0, -2 * M_PI * k * n / N);
        if (abs(sum) > bestPower) { bestPower = abs(sum); best = k; }
    }
    double f = best * rate / N;                // сав → Hz (савны өргөн = rate / N)

    const string names[] = {"C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"};
    int m = lround(69 + 12 * log2(f / 440));   // давтамж → нот
    cout << "Оргил: " << f << " Hz = " << names[m % 12] << m / 12 - 1 << "\n";
}
```

Савны өргөн 8000 / 2048 ≈ 3.9 Hz тул 440 Hz яг нэг саванд таардаггүй: 440 / 3.9 ≈ 112.6 → хамгийн ойр 113-р сав = **441.4 Hz** гарна. Гэсэн ч нот нь **A4** — нотны хооронд ~26 Hz зай байгаа тул хэдэн Hz-ийн алдаа хамаагүй. Demo-ийн бүтэн код: [demo.js](demo.js).
