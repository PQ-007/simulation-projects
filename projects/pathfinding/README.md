# Pathfinding

Google Maps таныг хамгийн хурдан замаар яаж хөтөлдөг вэ? Тоглоомын дүр хана мөргөлгүй зорьсон газартаа яаж очдог вэ? Хоёулаа ижил асуудал: **S-ээс G хүртэлх хамгийн сайн замыг олох**.

## Энгийнээр хэлбэл

Танихгүй хотод төөрсөн гэж төсөөл. Хоёр янзаар хайж болно:

- **Сохроор, бүх тийш жигд** — эхлээд 1 алхам хол бүх газрыг, дараа нь 2 алхам хол бүгдийг... Заавал олно, гэхдээ удаан.
- **Ухаалгаар** — "G зүүн хойд талд байгаа" гэдгийг мэдэж байгаа тул тийшээ чиглэсэн замуудыг түрүүлж шалгана.

| Algorithm | Хэрхэн хайдаг вэ | Хамгийн сайн замыг олох уу? |
| --- | --- | --- |
| **BFS** | Ус асгасан мэт бүх тийш жигд тэлнэ | Тийм (шавар байхгүй үед) |
| **DFS** | Нэг замаар аль болох гүн явна | Үгүй — тойруу зам олж болно |
| **Dijkstra** | Хамгийн "хямд" хүрсэн газраас үргэлжлүүлнэ | Тийм, шавартай үед ч |
| **A\*** | Dijkstra + "G хэр хол вэ" гэсэн таамаг | Тийм, бас хурдан |
| **Greedy** | Зөвхөн "G рүү хамгийн ойр харагдах" газар руу | Үгүй |

## Томьёо — алхам алхмаар

### 1. Зардал $g$ — "одоог хүртэл хэр их явсан бэ"

Энгийн нүд рүү алхах = **1**, шавар руу = **5**. Замын зардал = алхмуудын нийлбэр.

**Жишээ:** S → энгийн → шавар → энгийн → G гэвэл $g = 1 + 5 + 1 + 1 = 8$.

### 2. Таамаг $h$ — "G хүртэл ойролцоогоор хэр хол вэ"

Хана байхгүй гэж бодоод хэвтээ, босоо алхмаа тоолно (**Manhattan зай**):

$$
h = |x - x_G| + |y - y_G|
$$

$|\ |$ = "хасах тэмдгийг хая". **Жишээ:** бид $(1, 0)$-д, G нь $(3, 2)$-т. $h = |1 - 3| + |0 - 2| = 2 + 2 = 4$ алхам.

### 3. A\*-ийн оноо $f$

$$
f = g + h
$$

Үгээр: *"энд хүртэл явсан + цааш явах таамаг = нийт аялал хэр урт болох вэ."* A\* хамгийн бага $f$-тэй нүдийг түрүүлж шалгана.

**Жишээ.** S = $(0, 0)$, G = $(3, 2)$. S-ээс хоёр сонголт:

| Нүд | $g$ (явсан) | $h$ (таамаг) | $f = g + h$ |
| --- | --- | --- | --- |
| Баруун $(1, 0)$ — G руу | 1 | $2 + 2 = 4$ | **5** ✓ |
| Зүүн $(-1, 0)$ — G-ээс холдож | 1 | $4 + 2 = 6$ | 7 |

A\* баруун тийш явна — G руу. Dijkstra ($h$-гүй) хоёулаа $g = 1$ тул хоёулааг нь адилхан шалгаж цаг алдана.

## Нэг санаа авч үлдэх

> **Сайн таамаг хайлтыг хурдасгадаг.** A\*-ийн бүх нууц нь $f = g + h$ гэсэн нэг нэмэх үйлдэл.

## Код (C++)

Жижиг grid дээр A\* ажиллуулж хамгийн богино замын уртыг хэвлэдэг бүтэн программ:

```cpp
#include <array>
#include <climits>
#include <cstdlib>
#include <iostream>
#include <queue>
#include <string>
#include <vector>
using namespace std;

vector<string> grid = {          // # = хана, ~ = шавар (5), . = энгийн (1)
    "S..#....",
    ".#.#.##.",
    ".#...#..",
    ".####.#.",
    "..~~~..G",
};

int main() {
    int H = grid.size(), W = grid[0].size(), sx = 0, sy = 0, gx = 7, gy = 4;
    auto h = [&](int x, int y) { return abs(x - gx) + abs(y - gy); };   // Manhattan
    vector<vector<int>> g(H, vector<int>(W, INT_MAX));

    // {f, x, y} — priority_queue хамгийн бага f-ийг түрүүлж гаргана
    priority_queue<array<int, 3>, vector<array<int, 3>>, greater<>> open;
    g[sy][sx] = 0;
    open.push({h(sx, sy), sx, sy});
    int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};

    while (!open.empty()) {
        auto [f, x, y] = open.top(); open.pop();
        if (x == gx && y == gy) { cout << "Хамгийн хямд замын зардал: " << g[y][x] << "\n"; return 0; }
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || ny < 0 || nx >= W || ny >= H || grid[ny][nx] == '#') continue;
            int cost = g[y][x] + (grid[ny][nx] == '~' ? 5 : 1);
            if (cost < g[ny][nx]) {
                g[ny][nx] = cost;
                open.push({cost + h(nx, ny), nx, ny});     // f = g + h
            }
        }
    }
    cout << "Зам олдсонгүй\n";
}
```

Гаралт: `15` — шаврыг (5 зардал) тойрох зам нь шавар дундуур явахаас хямд. `h`-г үргэлж 0 болговол Dijkstra болно. Demo-ийн бүтэн код: [demo.js](demo.js).
